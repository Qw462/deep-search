# Git测试题

1. git的作用以及与svn的区别  

   ```
   作用：
   	记录文件变化
   	可以回退到之前的某个版本
   	多分支操作
   	多人协同开发
   	解决冲突
   区别：
   	git在离线时可以进行本地版本控制，而svn不可以
   ```

2. git本地基本操作的命令（单分支）

   ```
   init 初始化仓库
   add  将工作区的变化添加到暂存区
   commit 将暂存区的变化提交到版本区
   status 查看git状态
   reflog  查看历史版本记录
   reset   版本穿梭/回退
   diff   比较文件在不同区的差异
   restore  放弃文件修改
   rm     删除文件
   ```

3. git多分支操作的命令 

   ```
   branch   查看分支、创建分支
   checkout 切换分支
   merge    合并分支
   ```

4. 产生冲突的原因和解决办法

   ```
   原因：两个人改了某个分支的同一个文件代码，后提交的人就会出冲突
   解决：
   	1. 编辑好带冲突的合并文件代码
       2. git add .
       3. git commit -m "日志"
   ```

5. git远程操作的一系列命令

   ```
   remote   添加远程仓库/查看远程仓库地址
   push  将本地仓库推送到远程
   pull  拉取远程仓库更新到本地
   clone 克隆远程仓库产生本地仓库
   ```

6. PyCharm如何集成Git使用

   ```
   1. 给PyCharm配置git.exe路径
   2. 初始化本地仓库
   3. 配置git忽略
   4. 将项目文件代码提交到本地仓库
   5. 创建分支与切换分支
   6. 合并分支，并解决冲突问题
   ```

7. PyCharm如何集成Gitee使用

   ```
   1. 安装gitee插件
   2. 在插件中登陆连接Gitee(使用私有令牌方式)
   3. 将本地仓库分享到Gitee,自动生成远程仓库
   4. 在Gitee上将仓库设置为开源的（可选）
   5. 推送本地仓库更新到远程
   6. 拉取远程更新到本地
   7. 克隆远程仓库
   ```

8. 使用git进行项目管理的6个基本操作

   ```
   1. 创建本地仓库
   2. 创建远程仓库
   3. 将本地仓库推送到远程
   4. 如果本地改了代码，先提交再推送
   5. 如果远程仓库有变化，拉取到本地
   6. 克隆远程仓库生成本地仓库
   ```
